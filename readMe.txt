# 🎮 Number Guess Game

A simple and fun browser game where players try to **guess a secret number** within a limited number of attempts.

The game tells you **how many digits are correct and in the correct position** after each guess.

Built using **HTML, CSS, and JavaScript** and playable directly in the browser.

---

## ✨ Features

* 🔢 Randomly generated secret number
* 🎯 Feedback on **correct digits in correct positions**
* 📜 **Guess history** to track previous attempts
* 🔄 **Restart button** to start a new game anytime
* 🎚 **Difficulty levels**

  * Easy → 4 digit number
  * Medium → 5 digit number
  * Hard → 6 digit number
* 🌙 **Dark Mode**
* 🏆 **Leaderboard** (stored in browser using localStorage)
* 📱 **Mobile friendly UI**
* 🎬 Smooth animations for guesses

---

## 🎮 How To Play

1. Choose a **difficulty level**.
2. Enter a number with the required number of digits.
3. Click **Guess**.
4. The game will tell you **how many digits are correct and in the correct position**.
5. Keep guessing until you find the secret number.

You have **20 guesses** to win!

Example:

Secret number: `2312`

| Guess | Result      |
| ----- | ----------- |
| 3499  | 0 correct   |
| 2190  | 1 correct   |
| 2312  | 🎉 You win! |
